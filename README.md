# docker-tf06-GuilhermeBueno

 Instruções para Entrega no GitHub
Para que o trabalho seja avaliado, os alunos devem seguir estes passos:
Criar um Repositório Público no GitHub com o nome docker-tf06-[NOME-DO-ALUNO].
Subir os arquivos: docker-compose.yml, o diretório do build (com Dockerfile) e um arquivo README.md.
No README.md: Adicione prints (screenshots) ou a saída do terminal dos seguintes comandos:
docker-compose up -d (mostrando a criação dos recursos).
docker-compose ps (mostrando os serviços ativos).
Um teste de conectividade (ping) entre os contêineres
